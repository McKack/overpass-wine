# Contributing

Bug reports, test results and findings are very welcome. Open an issue with:

- what you saw;
- how to reproduce it;
- your Mac, your macOS version and your OverPass version.

A Collect Logs zip from OverPass helps a lot.

Pull requests must be written by people. We don't accept pull requests generated by AI agents or language
models, or opened in bulk. Using AI for your own research is fine: share what you found in an issue instead.

Keep pull requests small and about one thing. Say what was wrong and how you tested the fix, and follow the
existing code style.

Changes that aren't specific to macOS or OverPass belong upstream at [WineHQ](https://gitlab.winehq.org/wine/wine).
